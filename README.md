# Task-Manager-API

A RESTful API for managing tasks that allows users to create, read, update, and delete tasks. This project is designed as a scalable backend service that can be integrated with web or mobile applications.

# Description

Task Manager API provides endpoints for task management within a personal or team productivity system. It supports full CRUD operations and can be integrated with frontend applications such as web dashboards or mobile apps.task-manager-api

Technologies Used

Java - Spring Boot - Spring Data JPA - JPA Specifications - Maven - MySQL - REST API

# Features

 - User authentication with JWT
 - Secure endpoints using Spring Security
 - Password encryption with BCrypt
 - Task CRUD operations 
 - Dynamic task filtering using JPA Specifications 
 - Token management with refresh token support
 - Stateless authentication 
 - CORS configuration for frontend integration
